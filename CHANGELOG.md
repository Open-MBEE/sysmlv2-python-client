# Changelog

## 0.1.1

- Accept HTTP 201 and 200 when creating projects, commits, branches, and tags.
- Accept HTTP 200 and 204 when deleting projects, branches, and tags.
- Add optional Flexo service-token authentication alongside Bearer authentication.
- Add the OMG Beta 1 REST conformance suite and live client lifecycle checks.

## 0.1.0

- Initial PyPI packaging as `sysml-api-client`.
- Includes the existing `sysmlv2_client` client, exceptions, and `sysml_api` helpers.
